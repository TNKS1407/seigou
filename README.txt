# 整合 SEIGOU - RFマッチングアプリ

## 起動方法

### いちばん簡単
`index.html` をダブルクリックしてください。

### Windows
`start_windows.bat` をダブルクリックしても開けます。

## 中身
- `index.html` : アプリ本体です。ネット接続なしで動きます。
- `start_windows.bat` : Windows用の起動ファイルです。

## できること
- RFネタのプロフィール閲覧
- OPEN / MATCH / THRU ボタン
- MATCH履歴
- 相性アナライザ
- 高Q許容 ON/OFF
